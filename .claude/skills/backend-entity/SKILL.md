# Entidad + migración — estándar de cdr-backend

Patrón de entidad de `../ticket-backend` (`appticket/domain/entity/Holiday.java`, `appbase/domain/entity/Base.java`)
con las correcciones aprobadas: **Flyway**, enums **STRING**, `@Version`, FKs snake_case.
Convenciones completas: `docs/architecture/database-conventions.md`.

## 1. Proceso

1. Definir campos, tipos, nulos, unicidad, relaciones, si es catálogo (borrado lógico) o histórico (inmutable).
2. ¿Necesita `@Version`? Sí si varios usuarios pueden modificarla a la vez (`Order`, `Product`, `CashSession`).
3. Escribir la **migración** `src/main/resources/db/migration/V{n}__{descripcion}.sql` (n = siguiente libre).
4. Escribir la **entidad** que coincida exactamente (Hibernate `validate` falla si no).
5. Registrar el nombre español en `SpanishEntityNameProvider.NAME_MAP` (`"Addon" → "Adicional"`).
6. `.\gradlew.bat test` + arrancar en dev para que Flyway + `validate` comprueben el mapeo.

**Nunca** editar una migración ya aplicada en cualquier entorno: crear `V{n+1}__alter_...sql`.

## 2. Entidad de catálogo (extiende `Base`)

```java
@EqualsAndHashCode(onlyExplicitlyIncluded = true, callSuper = false)
@Entity
@NoArgsConstructor
@Getter
@Setter
@Table(name = "products")
public class Product extends Base {

    @EqualsAndHashCode.Include
    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Integer id;

    @Column(nullable = false, length = 100)
    private String name;

    @Column(length = 500)
    private String description;

    @Column(name = "image_base64", columnDefinition = "TEXT")
    private String imageBase64;

    @Column(nullable = false, precision = 12, scale = 2)
    private BigDecimal price;

    @Column(nullable = false)
    private Boolean available = true;          // agotado temporal ≠ inactivo

    @ManyToOne(fetch = FetchType.LAZY, optional = false)
    @JoinColumn(name = "category_id", nullable = false)
    private Category category;

    @ManyToMany(fetch = FetchType.LAZY)
    @JoinTable(name = "product_addons",
            joinColumns = @JoinColumn(name = "product_id"),
            inverseJoinColumns = @JoinColumn(name = "addon_id"))
    @JsonIgnore
    private Set<Addon> addons = new HashSet<>();

    @Version
    private Long version;
}
```

Diferencias deliberadas con la referencia: `@ManyToOne(fetch = LAZY)` (la referencia usa EAGER por
defecto; con LAZY las lecturas van por proyección JPQL y no se serializan proxies), `@Getter/@Setter`
en entidades con colecciones, FK `category_id` (no `categoryId`).

```sql
-- V2__catalog.sql (fragmento)
CREATE TABLE products (
    id            INTEGER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    category_id   INTEGER        NOT NULL,
    name          VARCHAR(100)   NOT NULL,
    description   VARCHAR(500),
    image_base64  TEXT,
    price         NUMERIC(12,2)  NOT NULL,
    available     BOOLEAN        NOT NULL DEFAULT TRUE,
    version       BIGINT         NOT NULL DEFAULT 0,
    active        BOOLEAN        NOT NULL DEFAULT TRUE,
    created_by    VARCHAR(150),
    updated_by    VARCHAR(150),
    created_at    TIMESTAMP,
    updated_at    TIMESTAMP,
    CONSTRAINT fk_products_categories FOREIGN KEY (category_id) REFERENCES categories(id) ON DELETE RESTRICT,
    CONSTRAINT ck_products_price_non_negative CHECK (price >= 0)
);
CREATE UNIQUE INDEX ux_products_name ON products (lower(name)) WHERE active;
CREATE INDEX ix_products_category_id ON products (category_id);
```

## 3. Entidad histórica (fotografía, inmutable)

```java
@Entity
@NoArgsConstructor
@Getter
@Setter
@Table(name = "order_items")
public class OrderItem extends Base {

    @Id @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Integer id;

    @ManyToOne(fetch = FetchType.LAZY, optional = false)
    @JoinColumn(name = "order_id", nullable = false)
    private Order order;

    @ManyToOne(fetch = FetchType.LAZY, optional = false)
    @JoinColumn(name = "product_id", nullable = false)
    private Product product;                    // trazabilidad

    @Column(name = "product_name", nullable = false, length = 100)
    private String productName;                 // FOTOGRAFÍA

    @Column(name = "category_name", nullable = false, length = 100)
    private String categoryName;                // FOTOGRAFÍA

    @Column(name = "unit_price", nullable = false, precision = 12, scale = 2)
    private BigDecimal unitPrice;               // FOTOGRAFÍA

    // quantity, addonsUnitTotal, lineSubtotal, notes, categoryId ...
}
```
Reglas: sin setters usados tras crear (el servicio no los actualiza), sin `DELETE` en repositorio
(no exponer `delete` en el servicio), `ON DELETE RESTRICT` en todas sus FKs.

## 4. Enums persistidos

```java
@Enumerated(EnumType.STRING)
@Column(nullable = false, length = 30)
private OrderStatusEnum status;
```
```sql
status VARCHAR(30) NOT NULL CHECK (status IN ('PENDING','IN_PREPARATION','READY','DELIVERED','CANCELLED'))
```
Añadir un valor al enum ⇒ nueva migración que reemplace el CHECK.

## 5. Checklist

- [ ] Migración `V{n}__...sql` nueva (no se editó ninguna existente).
- [ ] Tabla plural snake_case; FK `xxx_id` con `fk_` + `ON DELETE RESTRICT`; índices `ix_`/`ux_`; `CHECK` de invariantes.
- [ ] Columnas de `Base` presentes si la entidad extiende `Base`.
- [ ] Dinero `NUMERIC(12,2)` ↔ `BigDecimal` (`precision = 12, scale = 2`).
- [ ] Enums `STRING` + `CHECK`.
- [ ] `@Version` si hay concurrencia.
- [ ] Relaciones `LAZY`; colecciones inversas con `@JsonIgnore`.
- [ ] Nombre español en `SpanishEntityNameProvider`.
- [ ] Arranque en dev sin errores de `validate`.
